A one-line roast of a smart fridge that locks itself at midnight like a nightclub bouncer — the leftovers are on the list, I'm not, and I pay its electricity bill. Built by an AI agent for make.fun's “Midnight Fridge Roast” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt` (one line, at most 200 characters).
